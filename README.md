# CardMatch

This project is a Unity-based **Card Matching Game Prototype**, built as part of a technical assessment. It features a fully functional gameplay loop, JSON-driven level design, card animations, scoring system, and data-driven card placement using a custom Unity Editor tool.

> ⚠️ Note: This project was started from an empty Unity project and built incrementally with clean git commits for transparency and code review.

## ✨ Features

- ✅ Animated card flipping with continuous interaction
- ✅ Match logic with score tracking
- ✅ JSON-based level loader using manually placed positions
- ✅ In-editor **Level Editor Window** for exporting level JSON
- ✅ Supports dynamic card layouts
- ✅ Random image assignment from paired sprite list
- ✅ Basic sound effect placeholders (can be extended)
- ✅ Save system placeholder (for future implementation)
- ✅ Clean folder and prefab structure
- ✅ Frequent, meaningful git commits
